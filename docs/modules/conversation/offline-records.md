# 会话离线记录

## 已确认规则（2026-10-26）

- 已下载的已发送记录长期保存在当前设备，用户主动清理；不做 7 天自动过期。
- 退出登录清理该账号的本机已发送记录副本，服务器记录保留。账号切换清理原账号副本，存储按账号、小队和计划讨论隔离。
- 离队、被移除、计划不可见后，仍长期保留已下载的本机副本。联网明确返回无权访问时显示权限错误，不伪装成同步成功；断网可读此前下载的记录。保留副本不授予任何新的服务器访问权限。
- 手动清理仅删除本机已发送记录，不调用服务器删除接口、不删除未发送内容。重新联网打开会话会再次下载仍可访问的记录。
- 未发送内容继续存放于独立加密 outbox；本轮不增加未经确认的 7 天自动重试截止或删除策略。

## 实现边界

独立 Drift 数据库保存 AES-GCM 加密的已下载时间线；安全存储中保存独立于 outbox 的账号密钥。正文、作者名称及卡片快照全部加密；账号、Squad、计划、消息 ID、时间戳是分页索引，不缓存路线明文或私钥。仅保存已通过服务器可见性检查的投影，按 `(createdAt, id)` 分页，不捏造未下载的历史。

读取优先请求服务器，只有网络失败才回退本机页；明确权限/认证、格式错误和业务失败不回退。网络回退以界面提示标识，已读推进仍遵守前台且最新消息实际可见的规则。写入失败不能把服务器已成功发送的消息判为发送失败；缓存故障仅影响离线可用性。

清理立即废弃旧请求的缓存写入资格，串行清除记录并轮换缓存密钥；退出时暂停旧账号缓存读写，防止在途请求重新落盘。清理失败须显示错误，不将失败标为完成。已实现本机文件重开和账号/线程隔离的本地回归；此功能仍需实体设备断网/重启/退出验收。2026-10-27 新增 [本机记录只读入口](offline-cold-start.md)，SDK 会话未过期时可在断网冷启动后进入已下载记录，不依赖 profile、小队和计划列表联网恢复；完整业务页面仍需网络。

## 页面入口

「我的 → 清理本机聊天记录」需要确认范围；取消不清理。清理失败显示重试提示。主动退出会先完成本机已发送记录清理，失败时保留当前账号并提示重试，避免显示清理成功后遗留副本。会话显示本机副本提示；权限失败单独提示，不把本机记录当作服务器的当前授权。

## 离线冷启动规则（2026-10-26 已确认）

用户选择：登录会话过期后先联网登录。2026-10-27 已接入只读本机记录入口，不把缓存身份当作新服务器授权。

- 冷启动从 CloudBase SDK 公开的本机会话事件取得已有账号和绝对到期时间，不通过请求 profile 或小队/计划列表才能打开缓存，不自行保存额外 JWT 或刷新令牌。
- 只有已有会话身份与令牌 subject 一致、绝对期限明确且未过期时才可读取该账号缓存；期限缺失、格式错误、无会话或到期均拒绝读取。采用令牌 `exp` 与 SDK 绝对期限中较早者，不用 `expiresIn + 当前时间` 延长旧会话。
- 登录页及「我的」提供「本机聊天记录」入口；记录页保留 Squad 和计划讨论归属，读取已下载文字和卡片摘要，提供向前分页。没有本机记录时展示空状态。
- 该入口只读，不发消息、不重试 outbox、不推进已读、不访问财务/健康/路线接口；恢复完整功能需返回正常登录流程。
- 查看期间到期、恢复前台时发现到期或会话账号变化，立即隐藏原账号明文并阻止在途读取结果显示。缓存仍保留，不把会话自然到期当作用户退出。
- 明确退出或切换账号仍清理原账号本机副本；在 profile 尚未联网恢复时也必须从已有会话识别原账号。清理失败不显示成功。
- SDK 在线恢复有效登录会话后可重新读取；过期的本机副本不能自行延长授权。离线无法获知服务器尚未同步的撤销，以此前已下载副本的本机会话期限作为查看门槛。

增加加密的会话标题目录，以便冷启动不依赖在线列表。数据库 v1 已有记录保留并可用通用标题进入；新取得的 Squad/计划标题与正文使用同一账号缓存密钥加密，清理时一起删除。本地全量 434 项 Flutter 回归通过，模拟器与实体设备分别记录结果，详见 [冷启动实现与验收](offline-cold-start.md)。
