# 通知预算内的 SDK→原生续期交接

2026-10-31。接续 SDK 单实例顺序边界；变更先于实现。目标仍包括真实 APNs、桌面和签名真机，不用本地交接测试替代平台验收。

- 原通知从入口起使用同一单调时钟 25 秒总预算，completion 27 秒兜底。有效原生凭据直接取图；缺失/过期时只对已有且预览启用的同 scope 绑定请求 SDK 恢复。最多等待 8 秒，剩余时间传给原取图 actor，不重新获得 25 秒。
- SDK 只由现有主 Flutter engine 的同一 Auth 实例经 CloudBaseAuthGate 调用。不新开无协调 engine、不读取 SDK 私有存储、不把 refresh token 传原生。正常冷启动可以在预算内等待既有 engine 注册；未就绪则按时结束，不能宣称保证冷启动触达。
- 过期 SDK 身份仅保留匹配的既有原生会话引用，清像素和私有凭据。该引用不授权取图、绑定或写像素。明确退出/认证操作/身份错误仍删除会话引用。不能由已退出状态新建恢复引用。
- 原生准备一次性票据，锁定 binding/scope/generation/单调截止时间。回调只携带 ticket、scope、remainingMs。Dart 从本机配置和 SDK 生成材料；普通 JWT 的 subject/角色/绝对期限、网关、原 scope 均重验。只有原生 CAS 仍匹配且票据未过期，才能换代更新会话并保存短期 access JWT。票据不授权任何服务端访问，随后仍按已有成员/照片头复核取图。
- 原生同一时段只请求一次 SDK 交接。Dart 调用即使超时也不能提前释放 SDK 实际调用队列；晚到结果不得提交。原生票据在超时、退出、重绑、预览变更和清理时失效。旧 ticket 的取消不能删除新凭据。
- 交接期间只延后相同 scope 的正向 lifecycle 同步，避免 SDK 刷新事件先换代而使自己的票据失效；不同账号/环境的 ready 状态也视为撤权，拒绝/退出立即执行并取消交接；更早到期清理的晚到失败不得清除较新交接。结束后应用最新正向状态。App Group/Widget extension 保持无凭据、无网络。

验证：过期引用不授权；无引用/错 scope/预览关闭拒绝；过期/重绑/退出/重复票据拒绝；SDK正常/失败/晚回/队列超时；engine延迟注册/缺失；重复提示合并；取图共享原预算；正向事件不破坏交接而撤权立即清理；真实 SDK C + 原生桥。实际 APNs、系统冷启动、锁屏/重启/强制退出和桌面绘制须另有平台证据。
