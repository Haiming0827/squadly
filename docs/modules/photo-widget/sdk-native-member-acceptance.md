# 同一真实成员的 SDK 续期与原生取图验收

2026-10-31。补齐预算内交接检查点缺少的单条正向证据，不改生产权限和数据模型。

使用独立 staging、普通 A/C 账号和全新临时两人小队。A 通过邀请码让 C 加入，之后发布仓库内的 4×3 合成 JPEG。所有身份、邀请、上传、照片头与已读游标的允许断言均使用普通用户 JWT；服务端 Key 只允许在流程结束后清理本次返回/唯一标记的小队、媒体对象与提示队列。

独立 iOS 宿主通过公开 SDK 构造器承接 C 的受控会话，强制本地 SDK 期限过期。原生绑定的短期引用先自然到期，然后从原生恢复入口请求现有 Dart engine；Dart 实际刷新 C，会话轮换后经一次性票据保存原生短期访问材料。原生以同一个 C 的新材料完成成员、照片头、媒体、二次成员/头复核及组件缓存写入。要求显示目标合成照片、代次换新、期限不超过新 SDK/JWT 到期，重复提示不续租、不再次调用 SDK，后台取图不推进已读。

凭据只通过宿主 Documents 的预建 0600 输入/输出文件交给 Dart SDK；原生不接收 refresh token，App Group 不保存认证材料。C 轮换结果必须先收回忽略配置，再清理临时队伍和对象；失败也清理，无法确认的清理保留 0600 台账供恢复，不以全局删除兜底。

这条验证不经过 APNs，不证明系统通知冷启动、WidgetKit 桌面绘制或签名真机行为。仍须保留非成员反例及完整平台验收。
