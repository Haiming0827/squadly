## 2. 总体顺序与阶段门

**A：私有照片能到桌面 → B：不同成员关联回拍 → C：连续出现与周回顾。** A 内先验证 iOS，Android 在其垂直链路后推进。暂不扩理财、行情和健康报告，不先做支付；既有模块的数据与权限持续维护。

| 阶段 | 前置 | 通过条件 |
| --- | --- | --- |
| A 桌面链路 | A0 设计收口、媒体存储、签名设备、推送渠道 | iPhone / 无 GMS 小米双向发照，接收 App 后台仍可更新组件；权限反例通过 |
| B 回拍链路 | A 通过、照片回复契约 | 组件冷启动进入固定队 / 原消息；不同作者照片回复照片，照片墙 / 会话一致 |
| C 七天验证 | B 通过、队日规则、最小事件 | 同一小队 cohort 的连续三日 / 回拍 / 组件打开可计算，隐私与删除一致 |

不预估未经验证的工期。先将外部资格、签名与云服务配置列为依赖，能继续的 domain / mock / UI / SQL 工作独立推进；缺少真实配置不标记端到端完成。
