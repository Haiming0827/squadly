# 个人主页与分层设置（2026-11-03）

## 目的与页面边界

“我的”由设置列表变成当前账号的展示主页。主视觉为大头像与昵称，下方为成就勋章、小队封面、个人媒体资产区域；联系方式、开关、缓存清理及退出登录统一移到右上角齿轮设置。首页展示项只作为同一设置层级的快捷入口，不另建平行配置流程。

## 设置层级

- 设置 → 账号与资料 → 头像、昵称、账号与联系方式（真实模式）
- 设置 → 展示管理 → 成就勋章、小队封面、个人媒体资产
- 设置 → 通知与外观 → 通知设置、跟随系统/浅色/深色
- 设置 → 数据与隐私 → 本机聊天记录、清理本机聊天记录、错误报告授权、路线设备、数据来源与分享范围
- 设置 → 使用帮助
- 设置 → 退出登录

头像/昵称点击进入“账号与资料”；三类展示卡分别到达对应展示管理子页。返回使用正常页面栈；异步保存只作用发起时的账号。设置页面继续保留原错误报告主动授权、缓存清理确认和账号隔离。

## 展示内容与预留范围

- 主页不展示邮箱/手机号，不把健康、财务、路线或聊天正文作为装饰素材。它是本人可见的主页，不新增公开用户主页或跨队发现。
- 个人头像复用已有单次系统选图和 96×96 PNG 净化链路；预览后保存。通过新 domain 能力接口写现有 profiles.avatar_url，使用普通账号绑定的 PG client、本人 id 过滤和现有 owner UPDATE RLS；不新增表/扩大 GRANT，不改其他队友资料。头像沿用已有 profile 成员可见范围；不接收任意外部 URL。
- 勋章模块只有展示位和诚实的空状态，本轮不虚构已获得勋章、积分、连续打卡或排行；完整授勋规则另行设计。
- 小队封面由本人已加入小队的真实头像与名称组成展示卡；管理跳转现有小队资料，保留队长权限。独立封面图上传/裁切为后续能力，不新增虚假封面字段。
- 个人媒体资产预留视觉区域，管理入口接现有私密素材空间/数据工坊；本轮不声称已建完整照片/视频资产库，不自动公开或上传素材。

## 实现与验收

Home 是应用页面组合根，设置只通过 app provider/domain repository 调用数据能力。演示模式使用现有 DemoStore 并保留账号隔离；真实模式查询本人可见小队。未加载/失败时不展示虚假数量或空数据结论。

验证主页无设置开关/联系方式、齿轮入口、层级返回、昵称更新、头像取消/预览/保存失败、普通成员只读小队资料、深浅色主题、诊断授权、缓存确认、退出、窄屏与长中文昵称、账号切换不泄露旧账号展示。运行 flutter analyze 与全量 flutter test，并对 iOS 普通 App 构建和实际页面作单独记录。系统选图当前只有 iOS 原生来源；Android 不展示可用的选图操作。
