# 会话管理与常用小队设计（2026-11-03）

## 问题与范围

现有会话详情由首页临时创建 Scaffold，只有标题和消息区，没有连接已有小队管理；Squad 虽有 avatarUrl，却没有修改接口。列表仅实现消息有无筛选，没有个人备注、置顶和访问记录。此次补齐入口、数据与权限，保留原消息时间线和计划隐私边界。

用户已确认：个人会话备注只对自己可见；小队共享名称、简介、头像由队长修改；常用栏手动置顶优先，其次按最近 7 天打开次数、最近打开时间排列。备注不修改全局用户昵称或队友看到的名称。

## 交互规格

- 小队会话右上角“会话设置”：个人备注、置顶、共享头像、名称、简介、成员列表，以及现有成员管理入口。普通成员只可修改自己的备注和置顶；共享资料只读。
- “会话”标题左侧增加筛选图标，下拉选择全部、小队会话、计划讨论、已置顶、有消息、暂无消息；显示当前选择。没有可靠未读/@我/已完成语义的项目不伪装可用。
- 标题下方为横向圆形常用小队头像，点击直达该小队会话；仅含已置顶或最近 7 天打开过的小队，不把计划私聊混入。头像名称优先个人备注，列表搜索同时匹配备注、原名和消息。
- 主列表置顶小队优先，其余维持最新消息顺序。筛选只作用主列表，常用栏保持稳定。取消置顶后，仍可能因最近访问而出现在常用栏。
- 头像通过系统相册单次选择，客户端裁成居中正方形、96×96 PNG，重新编码不携带源照片元数据；预览后点击保存才发布，可恢复默认。保留当前头像、删除头像、选择新头像三种状态明确区分。

## 数据、隐私与架构

新增 domain 能力接口，不扩大既有 SquadRepository 的职责。个人设置绑定 squad_members.id，成员退出/移除后级联删除，重新入队不继承旧设置。只存备注、置顶时间、每日打开次数、最近打开时间，不存消息内容；访问明细仅本人可读。服务器按 Asia/Shanghai 日界限统计最近 7 天，单日计数上限 100。

头像是小队共享资料，沿用 squads.avatar_url，但此版本只写入有界 PNG data URI（96×96，二进制不超过 48KiB），不接收外部 URL。无需公开对象桶，成员通过现有 Squad RLS 读取；服务器校验大小、PNG 头和尺寸，客户端只解码有界图片。旧外部 URL 回退首字，不发起第三方网络请求。此缩略图格式独立于内容卡片/照片消息格式，不改变照片、轨迹、健康字段的授权规则。服务端头校验不能代替完整恶意图片扫描。

CloudBase 新增 owner-only RLS 表及 SECURITY DEFINER RPC。RPC 从 auth.uid() 得到本人身份、锁定当前 membership；共享更新同时锁小队和 captain membership，普通成员、未入队账号、匿名均不能修改。保留 squads 的 SELECT-only 客户端权限，不开放直接 UPDATE。

真实模式使用 CloudBase 用户 JWT；演示模式使用账号隔离的本地个人设置，走同一 domain 接口。Presentation 通过应用组合根注入仓库/头像选择能力，不引用其他 feature 的 data/presentation。

## 验收

覆盖：备注隔离、重入队清理、频次过期/置顶顺序、非队长拒绝、匿名拒绝、头像边界/默认/取消、RPC 异常提示、筛选与搜索、窄屏长名称、设置页入口。运行 Flutter analyze/test；SQL 本地回归不能作为云端验收证据。云端部署和模拟器交互验证结果另记实际证据。
