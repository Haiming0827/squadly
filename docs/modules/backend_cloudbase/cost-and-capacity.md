# CloudBase 成本估算

价格核对日期：2026-10-12。腾讯云套餐、资源点政策和地域价格会调整；购买前以控制台下单页和费用中心为准。本估算只覆盖 CloudBase，不含 Apple 开发者账号、短信签名/模板审核、第三方推送服务和人工运维成本。

## PG 用量单价（上海）

- PostgreSQL CPU：¥0.342 / 核·小时。
- PostgreSQL 存储：¥0.0005 / GB·小时，按共享实例实际存储计量。
- 云函数调用：¥0.0133 / 万次，另计 GB·秒和外网流量。
- 云存储标准容量：¥0.004 / GB·天；CDN 流量：¥0.21 / GB。
- 身份认证调用：¥0.5 / 万次；短信：¥0.05 / 条。
- 云开发 API 调用：¥0.1 / 万次；超出配额的 QPS、日志等另计。

按 730 小时估算，1 核持续运行一个月的 PG CPU 用量约 ¥249.66；10 GB 持续存储约 ¥3.65。它们是资源消耗的账面金额，会从套餐/资源包/按量额度依规则抵扣，不表示一定在套餐月费之外再收一遍。

## Squadly 预算建议

- **本地开发**：继续使用 `USE_DEMO_BACKEND=true`，CloudBase 成本为 ¥0。
- **CloudBase 联调**：先开免费体验环境完成 auth、REST、RLS、RPC 验证；如免费环境缺少所需能力或需要持续运行，升级个人版。预算起点为 ¥19.9/月，再观察 PG CPU/容量、认证、函数和存储资源点用量。
- **小规模内测**：从个人版开始，账单稳定运行一周后按费用中心实际消耗外推；至少单独留出短信和云存储/CDN流量预算。持续高 CPU、消息轮询、频繁函数调用会提高资源点消耗。
- **正式商用**：标准版适用于需要数据回档和较高配额的阶段；结合成员规模、在线连接、消息量、备份恢复目标和 SLA 再决定是否升级。不要仅按注册用户数估算数据库成本。

### 量级估算公式

```text
PG CPU 月消耗（元） = 核数 × 实际运行小时 × 0.342
PG 存储月消耗（元） = GB × 计费小时 × 0.0005
云函数调用消耗（元） = 调用次数 ÷ 10,000 × 0.0133
云存储容量月消耗（元） = GB × 天数 × 0.004
```

CloudBase 统一采用资源点抵扣：1000 点对应 ¥1；优先核实套餐附带资源点、已购资源包和是否开启按量计费。新加坡地域费率与上海不同，按资源点价格文档中的新加坡列单独核算。

## 预算和账单护栏

1. staging 与 production 使用不同环境；生产环境不可依赖免费体验期限。
2. 控制台开启账单告警，并检查是否允许超额按量计费；为认证短信、函数、数据库 CPU、存储和出网分别看用量。
3. 会话消息 adapter 当前使用 20 秒补取信号；若订阅数和在线时长增长，应优先评估官方 Realtime/推送，以减少轮询请求和延迟。
4. 14 天回档目前列在标准版及以上套餐能力；恢复演练和备份保留策略需纳入生产预算。
5. 真实用户上线前，记录 staging 一周的账单/资源点数据，再按活跃小队数和消息量外推；没有实测数据时不报单一“月成本”。
